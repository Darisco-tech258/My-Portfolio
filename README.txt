PROFILE IMAGE:
The home page currently uses a profile-photo placeholder because no image was supplied.
To add your photo:
1. Put your image in this folder, for example: profile.jpg
2. Open index.html.
3. Replace the <div class="photo-placeholder">...</div> with:
   <img class="profile-photo" src="profile.jpg" alt="Kayode Joash Daramola">

TECHNICAL NOTES:
- HTML5 semantic elements are used.
- No JavaScript is used.
- Pages are internally linked through the navigation and footer.
- The layout is responsive for desktop, tablet and mobile screens.
- Arial is the primary font.
- JSON-LD structured metadata is embedded in each page <head>.
- data.json models the site's content entities.
- The contact form uses a mailto action and therefore depends on the visitor having a configured email client.
